# Sila Union — Главная страница (кликабельный прототип)

Папка: `prototype/`

## Запуск
- Откройте `prototype/index.html` в браузере, либо запустите статический сервер:

```bash
cd /workspace/prototype && python3 -m http.server 5173
```

И откройте `http://localhost:5173`.

## Горячие клавиши
- Ctrl/⌘+K — открыть поиск
- N — меню «Создать»
- F — фильтры
- ? — краткая справка

## Темизация под брендбук Sila Union
Основные токены в `prototype/brand.css`. Замените значения на реальные из брендбука:
- Цвета: `--su-primary-500`, `--su-accent-500`, `--su-danger-500`, `--su-warning-500`, `--su-success-500`
- Поверхности/тексты: `--su-surface`, `--su-surface-2`, `--su-surface-3`, `--su-text`, `--su-text-muted`, `--su-border`
- Шрифты: `--su-font-sans` (подключите фирменный шрифт, если требуется)

Логотип: `prototype/assets/logo-sila-union.svg` — замените на официальный SVG.

## Содержимое
- `index.html` — разметка страницы: хедер, табы, 3 колонки, модальный поиск, боковая панель фильтров
- `brand.css` — токены бренда и системные переменные
- `styles.css` — стили компонентов, сетка 8pt, адаптив
- `app.js` — интерактивность: меню, диалоги, табы, рендер карточек, список задач
- `assets/logo-sila-union.svg` — заглушка логотипа

## Примечание
Это каркас и кликабельный прототип для UX-оценки. Логику редактирования моделей, импорта и права доступа нужно интегрировать с бэкендом/редактором позже.
